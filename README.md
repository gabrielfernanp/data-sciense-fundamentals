## About

This repository documents my progress studying Data Science, including data manipulation with Python, fundamental concepts of descriptive statistics, and linear regression models. The goal is to consolidate theoretical learning through practical Python examples, reproducing and expanding on the exercises proposed in the reference material.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/gabrielfernanp/data-science-studies.git
cd data-science-studies

# Create a virtual environment and install dependencies
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Run one of the example scripts/notebooks
python 03-statistics/correlation.py
```
