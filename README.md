## Sobre

Este repositório documenta meu progresso nos estudos de Data Science, incluindo a manipulação de dados com Python, conceitos fundamentais de estatística descritiva e modelos de regressão linear. O objetivo é consolidar o aprendizado teórico por meio de exemplos práticos em Python, reproduzindo e expandindo os exercícios propostos no material de referência.

## Conteúdo

### Python para Data Science

- Introdução ao Python aplicado à análise de dados
- Manipulação de dados com Pandas (DataFrames)
- Funções e preparação/limpeza de dados

### Matemática

- Funções lineares
- Plotagem de funções (Matplotlib)
- Coeficiente angular e intercepto

### Estatística

- Introdução à estatística descritiva
- Percentis
- Desvio padrão
- Variância
- Correlação
- Matriz de correlação
- Correlação vs. causalidade

### Regressão Linear

- Fundamentos de regressão linear
- Tabela e interpretação da regressão
- Coeficientes de regressão
- P-valor
- R-quadrado (R²)
- Estudo de caso aplicado

## Tecnologias Utilizadas

- **Python**
- **Pandas** — manipulação e análise de dados
- **NumPy** — operações numéricas
- **Matplotlib** — visualização de dados
- **SciPy** — funções estatísticas e regressão linear

## Como Executar

```bash
# Clone o repositório
git clone https://github.com/gabrielfernanp/data-science-studies.git
cd data-science-studies

# Crie um ambiente virtual e instale as dependências
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Execute um dos notebooks/scripts de exemplo
python 03-statistics/correlation.py
```

> Ajuste os comandos acima conforme os arquivos efetivamente presentes no repositório.
